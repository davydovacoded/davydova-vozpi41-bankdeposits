# Банковские вклады — лабораторная работа №3

Веб-приложение для учета клиентов банка, видов вкладов и банковских счетов, разработанное в рамках дисциплины «Разработка Web-приложений».

**Работающий сайт:** https://bank-deposits-lab.infinityfreeapp.com/

## Возможности

- Просмотр, добавление, редактирование и удаление клиентов, вкладов и счетов.
- Поиск и сортировка записей.
- Проверка вводимых данных.
- Формирование годовой ведомости доходов по закрытым счетам.
- Расчет суммы накопления и итогов по клиентам.
- Печать сформированного отчета.
- Адаптивный интерфейс.

## Используемые технологии

PHP, MySQL, PDO, HTML, CSS, JavaScript.

Размещение веб-приложения — InfinityFree.

## Структура проекта

| Папка | Назначение |
|---|---|
| `clients/` | Управление клиентами |
| `deposits/` | Управление видами вкладов |
| `accounts/` | Управление банковскими счетами |
| `report/` | Формирование годовой ведомости |
| `assets/` | Стили, скрипты и изображения |
| `includes/` | Подключение к БД и общие функции |
| `config/` | Пример конфигурации |
| `sql/` | SQL-скрипты создания и заполнения БД |
| `index.php` | Главная страница |

## База данных

В проекте используются три связанные таблицы:

- **Client** — сведения о клиентах банка.
- **Deposit** — информация о видах вкладов, сроках и процентных ставках.
- **Account** — банковские счета, связанные с клиентами и вкладами.

Связи между таблицами: `Client 1:N Account` и `Deposit 1:N Account`.

Для создания и заполнения базы данных используется файл `sql/bank-deposits-full.sql`.
