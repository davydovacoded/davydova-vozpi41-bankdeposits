# «Банк» — лабораторная работа №3 «Банковские вклады»

Учебное веб-приложение для ведения клиентов банка, видов вкладов и банковских счетов. Проект реализует операции CRUD, поиск и сортировку записей, а также формирование годовой ведомости доходов по закрытым счетам.

Работающий сайт: [https://bank-deposits-lab.infinityfreeapp.com/](https://bank-deposits-lab.infinityfreeapp.com/)

## Возможности

- просмотр, добавление, редактирование и удаление клиентов;
- просмотр, добавление, редактирование и удаление видов вкладов;
- просмотр, открытие, редактирование и удаление счетов;
- выбор клиента и вида вклада в форме счёта;
- поиск и сортировка данных без перезагрузки страницы;
- определение статуса счёта по дате закрытия и текущей дате;
- серверная валидация, CSRF-защита и подготовленные SQL-запросы;
- ведомость получения доходов по закрытым счетам за выбранный год;
- итоги по каждому клиенту и общие итоги по банку;
- печатная версия отчёта;
- адаптивный интерфейс на русском языке.

## Структура базы данных

База данных состоит из трёх таблиц.

### `Client`

- `id_client` — первичный ключ;
- `surname`, `name`, `patronymic` — ФИО клиента;
- `passport` — паспортные данные;
- `phone` — номер телефона.

### `Deposit`

- `id_deposit` — первичный ключ;
- `name` — название вклада;
- `term` — срок хранения в месяцах;
- `interest_rate` — годовая процентная ставка.

### `Account`

- `id_account` — первичный ключ;
- `account_number` — номер счёта;
- `open_date` — дата открытия;
- `close_date` — дата закрытия;
- `amount` — вложенная сумма;
- `id_client` — внешний ключ на `Client`;
- `id_deposit` — внешний ключ на `Deposit`.

Связи: `Client 1:N Account` и `Deposit 1:N Account`. Удаление клиента или вида вклада, связанного со счетами, ограничено внешними ключами.
